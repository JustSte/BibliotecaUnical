# Biblioteca Unical

Sistema per la gestione delle biblioteche UNICAL (es. Biblioteca BATS), con prenotazione di armadietti, posti a sedere e visualizzazione interattiva della mappa. Include QR code per confermare la presenza e timer automatico.

---

## Tecnologie utilizzate

- **Backend**: Spring Boot, Spring Security, PostgreSQL, Redis, OAuth2
- **Frontend**: Angular
- **Realtime**: Redis, WebSocket
- **Autenticazione**: Login con Google/terze parti
